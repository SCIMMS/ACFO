# ACFO v0.3.0 — geometry-prepared operator validation

Archived at [Zenodo DOI 10.5281/zenodo.22298532](https://doi.org/10.5281/zenodo.22298532),
from release commit `01ee59422399a554ff099877f8ad551535a41fe8`.
The DOI was added to the main-branch citation metadata after automatic archival;
the release tag and deposited source bytes remain unchanged.

This release adds a self-contained, two-machine validation supplement for
High-NA correspondence and support control, WAXS candidate ranking, Cartesian
ODT and coupled modal normal actions, radial CPSWF preparation and checked
cache reuse, and layered vector-wave composite operators with derivatives.

The supplement includes prespecified protocols and claim freeze, executable
component sources and tests, complete privacy-normalized returns with numerical
arrays and raw timings, the original second-machine ODT loader failure and its
same-input corrective rerun, independent audits, thirteen source-data CSVs,
and a portable distribution verifier.

Read [the release guide](../../validation/operator_synthesis_v0_3_0/README.md)
and [evidence boundaries](../../validation/operator_synthesis_v0_3_0/SCOPE_AND_RESULTS.md).

The evidence supports construction and numerical agreement in the tested
geometries/subspaces. WAXS timing in this particular payload lacks the strongest
equally contracted comparator; the ODT paired hot-speed interval is absent;
Windows strict bitwise radial failures remain recorded. The supplement supplies
neither a universal speed claim nor full-support/measured-data CPSWF reconstruction.
Composite timings compare its own fixed unfused and materialized implementations;
memory results describe retained arrays, not peak RSS or GPU memory.

Personal paths and deployment identifiers were normalized. Unlicensed third-
party raw intensity was omitted from a geometry-only input contract. Scientific
numeric values, outcomes and retained arrays were preserved and linked by
original/public hashes. The original top-level claim freeze is byte-identical.

The existing package API and v0.2.0 evidence remain available. New experimental
implementations are shipped in the isolated request components, preserving their
validated dependency snapshots. No new external benchmark was run for this release.

Verify from the repository root:

```bash
python validation/operator_synthesis_v0_3_0/verify.py
# Optional CPU smoke tests with NumPy/SciPy/pytest/periodictable:
python validation/operator_synthesis_v0_3_0/verify.py --smoke
```
