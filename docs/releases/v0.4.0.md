# ACFO v0.4.0 — structure guided reuse and composition

This release adds `validation/structure_reuse_v0_4_0/`, an isolated computational
validation package for selecting reusable factors, intermediate bases and update
supports from rotational coefficient structure. Existing package APIs and earlier
validation supplements are retained.

The package includes two-host replication of slab, radial 4f, WAXS tangents and
weighted ODT; separately frozen elliptic, matrix-free CPSWF preparation and basis
closure evidence; executable adapters, fixed contracts, raw process-level results,
numerical arrays, figure source tables, original/public provenance and verification.

The four new systems passed their numerical gates in 40 fresh workers across two
Linux hosts, with 18 focused tests per host. Performance remains workload dependent:
the slab many-RHS regime and relay single-use cold regime can favor baselines;
Nyström remains a strong relay comparator; full WAXS tangents and streaming are
distinct tradeoffs; ODT core acceleration has near-unity whole-operation ratios,
and sparse Fourier coupling can lose. Historical elliptic and CPSWF observations
are local evidence with their own fixed contracts.

Read [the supplement](../../validation/structure_reuse_v0_4_0/README.md) for numerical
coverage, exact paths, replay commands and limits. Run its `verify.py` for manifest
and numerical-gate checks, or `verify.py --smoke` for additional CPU tests. The
standalone release ZIP contains the same supplement bytes as the repository.

Private host addresses and personal paths are normalized in public derivatives.
Scientific numerical values and arrays are preserved and original hashes are kept
separate from public hashes. Original unpublished manuscripts and editorial
planning remain outside the release. License: ACFO Citation-Required License.
