# ACFO v0.2.0 manuscript validation release

This release accompanies *Geometry factorization and representation dispatch for repeated curved Fourier inference*. It contains the manuscript-facing implementation, figure files, source data, normalized validation evidence and executable numerical audits.

## Validated results

- WAXS: 8.279-fold speedup over the strongest eligible fused FINUFFT Type-3 comparator, with a 95% paired-bootstrap interval of 8.166-8.396 and preserved candidate ordering for the prespecified noise realization.
- NuMagSANS Example 3: 1.687-fold speedup for the shared 800-orientation Fourier backbone over the rotated-lattice affine Type-2 comparator, with a 95% orientation-resampling interval of 1.684-1.690. The five packing reductions are outside this timing ratio.
- UOB-100(Dy): measured-data candidate value J/T = 0.134132, with approximately 10^-14 relative-L2 agreement among ACFO, exact FFT and 59-atom direct evaluation. The contracted exact FFT is the fastest eligible representation for this native reciprocal grid.
- ODT: native Type-2 forward and Type-1 adjoint comparisons with setup and hot-application timings separated.
- High-NA Debye-Wolf: Supplementary accuracy-control evidence.

## Reproduce and audit

```bash
python -m pip install -e ".[test]"
python -m pytest -q
python scripts/verify_ncs_release_v020.py
python scripts/verify_validation_release.py
```

The release gate completed with 250 passing tests. The manuscript audit recomputes the headline intervals and validates all hashes under `validation/ncs_v0_2_0`.

Third-party raw archives are omitted. Their identities and original hashes are recorded in `validation/ncs_v0_2_0/PROVENANCE.json`; the public normalized copies remove machine-local paths and normalize line endings.

## Validated scope

The evidence covers eligible analytic, symmetry and dimensional contractions, representation dispatch, and repeated complete SO(2) orbits. General SO(3) sampling, incomplete rotational orbits, full-wave coupling and end-to-end retrieval remain outside the validated scope.
